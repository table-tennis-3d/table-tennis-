# フォーム3D

スポーツのフォームを自撮りした動画から、AIが全身の関節の位置を推定して **3Dモデルで再生** するWebアプリです。
卓球・テニス・ゴルフ・野球などのスイングや素振りを、好きな角度から・スローで・何度でも確認できます。

- インストール不要。ブラウザで開くだけで動きます（スマホ対応）
- **動画は端末の中だけで処理** され、サーバーには送信されません
- ビルド不要の静的サイトなので、GitHub Pages にそのまま置けます

## できること

| 機能 | 内容 |
| --- | --- |
| 3Dモデル化 | 動画を1コマずつ解析し、体の33か所の3D位置からデッサン人形風の3Dモデルを動かします（骨格表示にも切り替え可） |
| 自由な視点 | ドラッグで回転、ピンチ/ホイールで拡大。「撮影視点・正面・右から・左から・背面・真上」はワンタップ |
| 再生 | 0.1〜1倍のスロー再生、コマ送り、ループ。元動画に骨格を重ねて同時に表示 |
| 軌跡 | 利き手の手首の通り道を表示 |
| 数値・グラフ | 肘・膝・脇・股関節の角度、腰と肩の回転、捻転差（肩−腰）、上体の傾き、手首の速さ、腰の高さ、スタンス幅 |
| 山場の検出 | 手首がいちばん速い瞬間（インパクト付近）を自動で見つけてジャンプ |
| 比較 | お手本や前回の動画（または保存データ）を半透明の人形で重ね、山場で自動的にタイミングを合わせます。左右反転も可 |
| 保存 | 3D画面の画像（PNG）、3Dアニメーションの動画（MP4/WebM）、解析データ（JSON。あとで再解析せずに開ける） |

## 使い方

1. **撮る** — カメラを三脚などで固定し、全身が映るように撮影します。
2. **選ぶ** — 「動画を選ぶ」から動画を選び、解析する範囲（スイングの少し前〜少し後ろ）を決めます。
3. **作る** — 「3Dモデルを作る」を押すと解析が始まります。10秒の動画で数十秒〜1分ほどです（端末によります）。
4. **見る** — 3D画面を回したり、グラフをタップしてその瞬間に移動したりして確認します。

キーボード：スペースで再生／一時停止、← → で1コマ移動。

### うまく3Dにするための撮り方

- 頭から足先まで、全身が画面に収まるように
- 撮影中はカメラを動かさない
- 明るい場所で撮る（ブレを減らすため）。**60fps撮影がおすすめ**
- 体のひねりや腕の動きが見えるよう、斜め前か真横から
- 画面に映るのは1人だけに
- スローモーションで撮った動画は「スローモーション動画」の設定を合わせると、速さが実時間に換算されます

## 公開のしかた（GitHub Pages）

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」にして、公開したいブランチと `/ (root)` を選んで **Save**
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

### 手元で試す

ES Modules を使っているため、`index.html` をダブルクリックで開くと動きません。簡単なHTTPサーバーで開いてください。

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 仕組み

1. **姿勢推定** — [MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker)（`@mediapipe/tasks-vision` 0.10.21）で、動画の各コマをシークしながら推定します。腰の中心を原点としたメートル単位の3D座標（world landmarks）が得られます。GPUが使えない端末では自動的にCPU処理に切り替えます。
2. **後処理** — 検出できなかったコマの補間、見え具合（visibility）で重み付けした時間方向の平滑化（位相ずれなし）、足が床に着くような高さの補正、クリップ全体での体の向きの推定を行います。
3. **3D表示** — [three.js](https://threejs.org/)（0.170.0）で、関節の位置から人形の各パーツ（楕円体とテーパー付きの円柱）の位置と向きを毎フレーム計算して描きます。
4. **分析** — 3D座標から関節角度・回転角・速度を計算します。腰と肩の回転は、クリップ全体の平均の向きを0°として、上から見て左回りを＋にしています。

ライブラリとAIモデルは CDN（jsDelivr / Google）から読み込みます。外部のCDNに接続できない環境で使う場合は、ページの先頭で `window.FORM3D_ASSETS` を定義すると、同じサーバーに置いたファイルを使えます（書き方は `js/config.js` の先頭を参照）。

## 知っておいてほしい制限

- 1台のカメラの映像から3Dを **推定** しているため、カメラに対して前後（奥行き）方向の位置は誤差が大きめです。
- ラケット・バット・ボールは追跡しません。指先の細かい動きや手首の角度も大まかです。
- 体の中心（腰）を基準にしているため、フットワークによる前後左右の移動は再現されません（上下の動きは「足を床に接地させる」で表現しています）。
- 角度や速さは目安です。同じ場所・同じ角度で撮った動画どうしで比べると、変化が分かりやすくなります。
- 対応ブラウザ：最新の Chrome / Edge / Safari（iOS 16.4以降）/ Firefox。iPhone の「高効率（HEVC）」形式の動画は、ブラウザによって再生できないことがあります。その場合は「設定 › カメラ › フォーマット › 互換性優先」で撮影してください。

## ファイル構成

```
index.html            画面の構造
css/style.css         見た目
js/main.js            画面の制御（読み込み・解析・再生・設定・比較・保存）
js/pose-extractor.js  MediaPipe で動画から姿勢を推定
js/motion.js          補間・平滑化・床の補正・体の向き
js/analysis.js        角度・回転・速さ・山場の検出
js/viewer3d.js        three.js による3D表示（人形・骨格・軌跡・比較）
js/overlay2d.js       元動画への骨格の重ね描き
js/chart.js           グラフ
js/io.js              解析データ（JSON）の保存と読み込み
js/landmarks.js       33点の定義
js/config.js          ライブラリ・モデルの読み込み先
```
